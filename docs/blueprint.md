# **App Name**: Excel to PDF Converter

## Core Features:

- Excel File Upload: Allow users to upload an Excel file for processing.
- Data Extraction: Extract data from the uploaded Excel file.
- PDF Generation: Create a PDF document with a separate page for each unique 'N doc' value.
- Data Grouping: Group rows based on the 'N doc' column.
- Totals Calculation: Calculate totals for numerical columns within each group (e.g., sum of 'Valor a pagar').
- Formatted Output: Display each group with column headers and calculated totals at the bottom of each group.
- PDF Download: Enable users to download the generated PDF.

## Style Guidelines:

- Primary color: Light green (#B2D430), referencing 'Reporte utilidad venta en verde'.
- Background color: Very light green (#F0F5E4), providing a subtle contrast.
- Accent color: Pale yellow (#F5E36E), analogous to light green for highlighting totals.
- Headline font: 'Poppins' (sans-serif) for column headers, short and fashion oriented. Body font: 'PT Sans' (sans-serif) as body text, which provides the option for legibility at small point sizes.
- Clear tabular layout for presenting data extracted from Excel, mirroring the original format.
- Simple file upload icon for ease of use.
- Subtle loading animation while the PDF is generated.
